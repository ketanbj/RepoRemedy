# RepoAuditor Fixed User Stories

## AUD-01 Auditor coordination [P0]

As a repository auditor, I want to coordinate the review and improvement of multiple repositories so that I can consistently support maintainers in addressing security and software engineering gaps at scale.

## AUD-02 Auditor proposed changes [P0]

As a repository auditor, I want identified gaps to lead to proposed changes that maintainers can readily review and adopt so that my findings result in practical repository improvements.

## MNT-01 Maintainer independent use [P0]

As a repository maintainer, I want to obtain and act on proposed improvements easily for my own repository so that I can improve its security and engineering practices without depending on an external auditor.

## MNT-02 Maintainer informed adoption [P1]

As a repository maintainer, I want to understand the purpose, impact, and effort of proposed changes so that I can quickly decide whether to adopt or adapt them for my project.

## MNT-03 Maintainer feedback [P1]

As a repository maintainer, I want to communicate to the auditor whether the proposed changes are useful, too difficult, or need adjustment so that future suggestions better reflect my project’s needs and constraints.
